# Plugin `leciva` (registr léčiv SÚKL DLP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plugin pro vyhledávání léčivých přípravků registrovaných v ČR (SÚKL DLP), použitelný hlavně z chatu.

**Architecture:** Vzor `ares` — jediná Rust binárka `leciva-cli` obaluje veřejné SÚKL DLP REST API + lokální vyhledávací index. Hledání podle názvu jede z lokálního indexu (API neumí název→kód), detail/složení z živého API podle kódu. Index se stáhne z měsíčního open-data dumpu: poprvé přes `postInstall`, dál přes deklarovanou měsíční automatizaci, s lazy pojistkou při použití. Žádné UI, žádný API klíč, data v `~/.cdx/apps/leciva/`.

**Tech Stack:** Rust 2021, `clap` (CLI), `reqwest` blocking + rustls (HTTP), `zip` (dump), `encoding_rs` (cp1250→UTF-8), `serde`/`serde_json` (výstup + manifest), `anyhow`. Build přes Docker (`rust:1.86.0-slim`, vzor ares `build.sh`).

## Global Constraints

- Binárka: `leciva-cli`. Plugin/skill: `leciva`. (Vzor `znamky`/`insolvence` — místní název, ne anglický překlad.)
- Výstup vždy **JSON na stdout**; při chybě `ERROR: …` na stderr + exit kód 2 (vzor ares `main.rs`).
- DLP API base: `https://prehledy.sukl.cz/dlp/v1` (override env `SUKL_DLP_BASE_URL`). Open-data base: `https://opendata.sukl.cz` (override env `SUKL_OPENDATA_BASE_URL`). Vše **bez API klíče**.
- Data dir: `~/.cdx/apps/leciva/`, home z env `CODEXIS_PUBLIC_USER_HOME` (fallback `~`). Ne `~/.local/share/`, ne plugin složka.
- Kadence dumpu: měsíčně. Cron automatizace `0 3 1 * *`. Žádný cron častěji.
- Resolve URL dumpu: odvodit z `datumVydani` (`YYYY-MM-DD` → `YYYYMMDD`): `<<opendata>>/soubory/SOD<YYYYMMDD>/DLP<YYYYMMDD>.zip`.
- CSV ze SÚKL: oddělovač `;`, kódování **Windows-1250**, parsovat podle **názvu sloupce** (hlavička `KOD_SUKL;…;NAZEV;SILA;…;DOPLNEK;…`).
- Atomicita refreshe: stavět do temp → validovat (rowCount > 10000) → atomický rename → **až nakonec** zapsat `manifest.json`. Při selhání nechat starou verzi.
- v1 příkazy: `search`, `detail`, `slozeni`, `refresh`, `index status`, `api get`. Odložené na v2: `latka`, `dokumenty`, `ceny`, publikování zdrojů přes daemon secret.

```rust
fn split_semicolon(line: &str) -> Vec<&str> {
    line.split(';').collect()
}

fn col_index(header: &[&str], name: &str) -> Result<usize> {
    header
        .iter()
        .position(|h| h.trim() == name)
        .ok_or_else(|| anyhow!("CSV missing column {name}"))
}

pub fn build_tsv_from_csv(csv: &str) -> Result<(String, usize)> {
    let mut lines = csv.lines();
    let header_line = lines.next().ok_or_else(|| anyhow!("empty CSV"))?;
    let header = split_semicolon(header_line);
    let i_kod = col_index(&header, "KOD_SUKL")?;
    let i_nazev = col_index(&header, "NAZEV")?;
    let i_sila = col_index(&header, "SILA")?;
    let i_doplnek = col_index(&header, "DOPLNEK")?;

    let mut out = String::new();
    let mut count = 0usize;
    for line in lines {
        if line.trim().is_empty() {
            continue;
        }
        let cols = split_semicolon(line);
        let get = |i: usize| cols.get(i).map(|s| s.trim()).unwrap_or("");
        // tab-separated; tabuly v datech nahraď mezerou pro jistotu
        let row = format!(
            "{}\t{}\t{}\t{}",
            get(i_kod).replace('\t', " "),
            get(i_nazev).replace('\t', " "),
            get(i_sila).replace('\t', " "),
            get(i_doplnek).replace('\t', " "),
        );
        out.push_str(&row);
        out.push('\n');
        count += 1;
    }
    Ok((out, count))
}

pub fn parse_tsv(tsv: &str) -> Index {
    let entries = tsv
        .lines()
        .filter(|l| !l.trim().is_empty())
        .filter_map(|l| {
            let mut p = l.split('\t');
            Some(Entry {
                kod: p.next()?.to_string(),
                nazev: p.next()?.to_string(),
                sila: p.next().unwrap_or("").to_string(),
                doplnek: p.next().unwrap_or("").to_string(),
            })
        })
        .collect();
    Index { entries }
}

impl Index {
    pub fn search(&self, query: &str, limit: usize) -> Vec<Entry> {
        let q = query.to_lowercase();
        self.entries
            .iter()
            .filter(|e| e.nazev.to_lowercase().contains(&q))
            .take(limit)
            .cloned()
            .collect()
    }
}
```

use crate::paths;

impl Manifest {
    /// Porovnání ISO datumů jako string funguje (YYYY-MM-DD…), je lexikografické.
    pub fn is_older_than(&self, remote_platnost_od: &str) -> bool {
        self.platnost_od.as_str() < remote_platnost_od
    }

    pub fn save(&self) -> Result<()> {
        let path = paths::manifest_path();
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        let json = serde_json::to_string_pretty(self)?;
        std::fs::write(path, json)?;
        Ok(())
    }
}

pub fn load() -> Option<Manifest> {
    let data = std::fs::read_to_string(paths::manifest_path()).ok()?;
    serde_json::from_str(&data).ok()
}

/// Stale = chybí lokální manifest, nebo je lokální starší než vzdálená dávka.
pub fn is_stale(remote_platnost_od: &str) -> bool {
    match load() {
        None => true,
        Some(m) => m.is_older_than(remote_platnost_od),
    }
}

```rust
pub struct SuklClient {
    client: Client,
    base_url: String,
}

impl SuklClient {
    pub fn new() -> Result<Self> {
        let base_url = std::env::var("SUKL_DLP_BASE_URL")
            .unwrap_or_else(|_| DEFAULT_DLP_BASE.to_string())
            .trim_end_matches('/')
            .to_string();
        let client = Client::builder()
            .user_agent(USER_AGENT_VALUE)
            .timeout(Duration::from_secs(120))
            .build()?;
        Ok(Self { client, base_url })
    }

    fn url_for(&self, path: &str) -> String {
        if path.starts_with("http://") || path.starts_with("https://") {
            return path.to_string();
        }
        if path.starts_with('/') {
            format!("{}{}", self.base_url, path)
        } else {
            format!("{}/{}", self.base_url, path)
        }
    }

    pub fn get(&self, path: &str) -> Result<String> {
        let url = self.url_for(path);
        let resp = self.client.get(&url).header(ACCEPT, "application/json").send()?;
        let status = resp.status();
        let body = resp.text().unwrap_or_default();
        if status.is_success() {
            Ok(body)
        } else {
            Err(anyhow!("HTTP {status} on GET {url}\n{}", body.trim()))
        }
    }

    pub fn get_bytes(&self, url: &str) -> Result<Vec<u8>> {
        let resp = self.client.get(url).send()?;
        let status = resp.status();
        if !status.is_success() {
            return Err(anyhow!("HTTP {status} on GET {url}"));
        }
        Ok(resp.bytes()?.to_vec())
    }

    pub fn aktualni_dlpo(&self) -> Result<Davka> {
        let body = self.get("/aktualni-davky")?;

pub fn zip_url_from_datum(opendata_base: &str, datum_vydani: &str) -> Result<String> {
    // "2026-05-27T00:00:00" nebo "2026-05-27" → "20260527"
    let date = datum_vydani.get(0..10).ok_or_else(|| anyhow!("bad datumVydani: {datum_vydani}"))?;
    let compact: String = date.chars().filter(|c| c.is_ascii_digit()).collect();
    if compact.len() != 8 {
        return Err(anyhow!("bad datumVydani: {datum_vydani}"));
    }
    Ok(format!(
        "{}/soubory/SOD{}/DLP{}.zip",
        opendata_base.trim_end_matches('/'),
        compact,
        compact
    ))
}

    date.replace('-', ".")

use crate::decode::cp1250_to_utf8;
use crate::http::{opendata_base, SuklClient};
use crate::index::build_tsv_from_csv;
use crate::manifest::{is_stale, Manifest};
use crate::paths;

const CSV_NAME: &str = "dlp_lecivepripravky.csv";
const MIN_ROWS: usize = 10_000;

#[derive(serde::Serialize)]
#[serde(rename_all = "camelCase")]
pub struct RefreshOutcome {
    pub updated: bool,
    pub batch: String,
    pub row_count: usize,
}

pub fn extract_lecivepripravky_csv(zip_bytes: &[u8]) -> Result<Vec<u8>> {
    let mut archive = zip::ZipArchive::new(Cursor::new(zip_bytes))
        .map_err(|e| anyhow!("cannot open DLP zip: {e}"))?;
    let mut file = archive
        .by_name(CSV_NAME)
        .map_err(|e| anyhow!("{CSV_NAME} not in DLP zip: {e}"))?;
    let mut buf = Vec::new();
    file.read_to_end(&mut buf)?;
    Ok(buf)
}

fn now_unix() -> u64 {
    std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .map(|d| d.as_secs())
        .unwrap_or(0)
}

pub fn refresh(client: &SuklClient, force: bool) -> Result<RefreshOutcome> {
    let dlpo = client.aktualni_dlpo()?;
    let batch = batch_label(&dlpo.platnost_od);

    if !force && !is_stale(&dlpo.platnost_od) {
        return Ok(RefreshOutcome { updated: false, batch, row_count: 0 });
    }

    let url = zip_url_from_datum(&opendata_base(), &dlpo.datum_vydani)?;
    let zip_bytes = client.get_bytes(&url)?;
    let csv_bytes = extract_lecivepripravky_csv(&zip_bytes)?;
    let csv = cp1250_to_utf8(&csv_bytes);
    let (tsv, row_count) = build_tsv_from_csv(&csv)?;

    if row_count < MIN_ROWS {
        return Err(anyhow!("refused index: only {row_count} rows (< {MIN_ROWS})"));
    }

    let app_dir = paths::app_dir();
    std::fs::create_dir_all(&app_dir)?;
    // 1) zapiš index do temp, 2) atomicky přejmenuj, 3) až pak manifest
    let tmp = app_dir.join("index.tsv.tmp");
    std::fs::write(&tmp, tsv)?;
    std::fs::rename(&tmp, paths::index_path())?;

    let manifest = Manifest {
        batch: batch.clone(),
        platnost_od: dlpo.platnost_od.clone(),
        downloaded_at: now_unix(),
        row_count,
    };
    manifest.save()?;

    Ok(RefreshOutcome { updated: true, batch, row_count })
}
```

use clap::{Parser, Subcommand};
use serde_json::json;

use crate::dataset;

const ROOT_HELP: &str = "\
leciva-cli — vyhledávání léčivých přípravků (SÚKL DLP).

Výstup: JSON na stdout (zpracuj `jq`); při chybě `ERROR:` na stderr + nenulový exit.
Hledání podle názvu jede z lokálního indexu (stáhne se sám při prvním použití),
detail/složení z živého API podle kódu SÚKL.

Příklady:
  leciva-cli search \"paralen\"
  leciva-cli detail 0182362
  leciva-cli slozeni 0182362
  leciva-cli refresh
  leciva-cli index status
  leciva-cli api get \"/lecive-pripravky/0182362\"
";

#[derive(Parser, Debug)]
#[command(name = "leciva-cli", version, long_about = ROOT_HELP, arg_required_else_help = true)]
pub struct Cli {
    #[command(subcommand)]
    pub command: Command,
}

#[derive(Subcommand, Debug)]
pub enum Command {
    /// Hledání léku podle názvu (lokální index).
    Search {
        query: String,
        #[arg(long, default_value_t = 20)]
        limit: usize,
    },
    /// Detail léku podle kódu SÚKL (živé API).
    Detail { kod: String },
    /// Složení léku podle kódu SÚKL (živé API).
    Slozeni { kod: String },
    /// Stáhnout/přestavět lokální index.
    Refresh {
        #[arg(long)]
        force: bool,
    },
    /// Stav lokálního indexu.
    #[command(subcommand)]
    Index(IndexCommand),
    /// Přímý přístup na DLP API (escape hatch).
    #[command(subcommand)]
    Api(ApiCommand),
}

#[derive(Subcommand, Debug)]
pub enum IndexCommand {
    /// Vypíše manifest (verze/stáří indexu).
    Status,
}

#[derive(Subcommand, Debug)]
pub enum ApiCommand {
    /// GET libovolného DLP endpointu.
    Get { path: String },
}

fn ensure_index(client: &SuklClient) -> Result<()> {
    if paths::index_path().exists() && paths::manifest_path().exists() {
        return Ok(());
    }
    dataset::refresh(client, true)?;
    Ok(())
}

fn load_index() -> Result<Index> {
    let tsv = std::fs::read_to_string(paths::index_path())
        .map_err(|e| anyhow!("index not available: {e}"))?;
    Ok(index::parse_tsv(&tsv))
}

fn print_json(value: &serde_json::Value) {
    println!("{}", serde_json::to_string_pretty(value).unwrap_or_else(|_| value.to_string()));
}

fn print_raw(body: &str) {
    print!("{body}");
    if !body.ends_with('\n') {
        println!();
    }
}

pub fn run() -> Result<()> {
    let cli = Cli::parse();
    let client = SuklClient::new()?;

    match cli.command {
        Command::Search { query, limit } => {
            ensure_index(&client)?;
            let idx = load_index()?;
            let hits = idx.search(&query, limit);
            print_json(&json!({ "query": query, "count": hits.len(), "results": hits }));
        }
        Command::Detail { kod } => {
            let body = client.get(&format!("/lecive-pripravky/{kod}"))?;
            print_raw(&body);
        }
        Command::Slozeni { kod } => {
            let body = client.get(&format!("/slozeni/{kod}"))?;
            print_raw(&body);
        }
        Command::Refresh { force } => {
            let outcome = dataset::refresh(&client, force)?;
            print_json(&serde_json::to_value(&outcome)?);
        }
        Command::Index(IndexCommand::Status) => {
            match manifest::load() {
                Some(m) => print_json(&serde_json::to_value(&m)?),
                None => print_json(&json!({ "status": "missing" })),
            }
        }
        Command::Api(ApiCommand::Get { path }) => {
            let body = client.get(&path)?;
            print_raw(&body);
        }
    }
    Ok(())
}

# Léčiva — databáze léčivých přípravků SÚKL (DLP)

Jediný nástroj — **`leciva-cli`** — obaluje veřejné SÚKL DLP REST API
(`https://prehledy.sukl.cz/dlp/v1`) a lokální vyhledávací index.

**IMPORTANT:** Jediný nástroj je `leciva-cli`. Nevolej `curl` ani jiné nástroje.
Předpokládej, že `leciva-cli` je nainstalovaný v `PATH`.

**IMPORTANT:** Když `leciva-cli` vypíše `ERROR:` (např. `HTTP 404 …`), zastav se a
nahlas to uživateli. Nezkoušej slepě znovu.

## Klíče

SÚKL API neumí hledat podle názvu — má jen `kód → detail`. Proto:
1. název → kód: `leciva-cli search "<text>"` (lokální index)
2. kód → vše: `leciva-cli detail <kod>`, `leciva-cli slozeni <kod>`

Index se stáhne sám při prvním použití. Žádný API klíč není potřeba.

## Příkazy

```bash
leciva-cli search "paralen"        # → [{kodSukl, nazev, sila, doplnek}]
leciva-cli detail 0182362          # detail léku (JSON ze SÚKL)
leciva-cli slozeni 0182362         # účinné látky + množství
leciva-cli refresh                 # přestavět index (běží i jako měsíční automatizace)
leciva-cli index status            # verze/stáří indexu
leciva-cli api get "/lecive-pripravky/0182362"   # přímý DLP endpoint
```

Když se uživatel ptá na lék jménem: `search` → vyber kód → `detail`/`slozeni`.
