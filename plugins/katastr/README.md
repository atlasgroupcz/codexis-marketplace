## Co to je?

Doplněk pro přístup do Katastru nemovitostí ČR přes oficiální API ČÚZK. Zvládne
jednorázové dotazy i dlouhodobé sledování katastrálních řízení.

## Co v něm najdete?

### Parcely, stavby a jednotky
Vyhledání podle čísla, adresy nebo katastrálního území. Výměra, druh pozemku, způsob
využití, technické údaje o stavbě.

### List vlastnictví
Číslo LV a nemovitosti, které jsou na něm zapsané. Jména vlastníků a úplný výpis
práv veřejné API ČÚZK neposkytuje - k těm vede oficiální výpis z listu vlastnictví
a doplněk vám k němu dá číslo LV, se kterým si o něj řeknete.

### Plomby a řízení
Zjistíte, jestli u nemovitosti neběží řízení, které ji "zamyká" - typicky se to ověřuje
před koupí.

### Adresy z RÚIAN
Dohledání nemovitosti podle adresy.

### Sledování řízení
Vklad nebo záznam si necháte hlídat a změnu stavu se dozvíte automaticky.

## K čemu se to hodí v praxi?

- **Před koupí nemovitosti** - na kterém LV nemovitost je a neběží-li plomba nebo cizí řízení.
- **Průběh vkladu** - po podání návrhu hlídáte, kdy je právo zapsáno.
- **Podklady do smlouvy** - přesné označení nemovitosti podle katastru.
- **Portfolio nemovitostí** - všechna sledovaná řízení na jednom místě.

## Nastavení

Doplněk potřebuje API klíč ze zákaznického portálu ČÚZK (zdarma, přihlášení Identitou
občana nebo účtem pro dálkový přístup). Klíč vložíte v aplikaci **Katastr - sledovaná
řízení** pod ikonou ozubeného kola, nebo o to požádáte asistenta v konverzaci.

## Součásti pluginu

### Katastr - sledovaná řízení (aplikace)
Tabulka sledovaných řízení, přidávání a odebírání, obnovení stavu a správa API klíče.

### Vyhledávání v konverzaci
Jednorázové dotazy na parcely, stavby, jednotky a LV zvládnete přímo v chatu.

## Zdroj dat

Katastr nemovitostí ČR, Český úřad zeměměřický a katastrální (ČÚZK).
