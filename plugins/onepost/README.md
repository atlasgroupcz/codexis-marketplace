## Co to je?

Doplněk propojuje asistenta s ONEPOSTem, přes který vaše organizace obsluhuje datové
schránky (ISDS). Ve zprávách se dá hledat, číst je i s přílohami, stahovat nové
z ISDS a odesílat připravené koncepty - bez přepínání do jiné aplikace.

## Nastavení

Nastavte API klíč přes aplikaci **ONEPOST API klíč**:

1. Otevřete aplikaci ONEPOST API klíč.
2. Klikněte na **Otevřít ONEPOST** a v profilu vygenerujte klíč.
3. Zvolte typ přístupu - **Pouze čtení** pro prohlížení dat, nebo **Čtení a akce** pro operace jménem uživatele.
4. Vložte klíč do pole a uložte - agent ho ihned ověří.

Klíč se ukládá lokálně do konfigurace pluginu a kdykoli ho můžete přepsat nebo smazat.

## Co plugin umí

- Přehled datových schránek a složek
- Čtení zpráv a jejich příloh
- Vyhledávání ve zprávách
- Stažení a příjem nových zpráv z ISDS (vyžaduje přístup *Čtení a akce*)
- Nahrání přílohy pro koncept, vytvoření/editace konceptu a odeslání konceptu (vyžaduje přístup *Čtení a akce*)

## K čemu se to hodí v praxi?

- **Dohledání zprávy** - „kdy nám přišlo rozhodnutí od toho úřadu" napříč schránkami
  i složkami, místo ručního proklikávání.
- **Práce s přílohami** - přílohu si necháte přečíst a rovnou z ní odpovědět.
- **Příprava odpovědi** - koncept vznikne i s přílohou a odešle se, až ho schválíte.
- **Přehled napříč schránkami** - když jich organizace obsluhuje víc.

## Zdroj dat

ONEPOST vaší organizace, nad Informačním systémem datových schránek (ISDS). Rozsah
je omezen vaším API klíčem a typem přístupu, který jste mu dal.
