# Judikatura a web scraping

## Kdy načíst

Použij při žádosti o česká rozhodnutí k web scrapingu, data scrapingu, crawlerům, API, databázím nebo automatizovanému stahování dat.

## Feedback-derived failure

Reálný negativní feedback zachytil stav, kdy asistent po rozsáhlé sérii vyhledávacích tool calls nevygeneroval žádnou uživatelskou odpověď. Skill proto musí hlídat dokončení rešerše i transparentní hranici její úplnosti.

## Rešeršní matice

Hledej po samostatných větvích:

| Větev | Výrazy a právní režim |
|---|---|
| technika | scraping, web scraping, data scraping, crawling, spider, parser, robot |
| databáze | vytěžování, zužitkování, podstatná část, opakované použití nepodstatných částí |
| autorské právo | rozmnožování, dočasná kopie, software, obcházení ochrany |
| smlouva | obchodní podmínky, zákaz automatizovaného přístupu, porušení licence |
| nekalá soutěž | parazitování, generální klauzule, obchodní tajemství |
| technický přístup | API, rate limit, autentizace, neoprávněný přístup |
| ochrana údajů | osobní údaje, veřejně dostupný zdroj, další zpracování |

## Postup

1. Spusť více úzkých dotazů v `JD`; jeden anglický výraz nestačí.
2. Pro každý nález otevři plné rozhodnutí a ověř skutkový děj, právní otázku, výrok a procesní výsledek.
3. Odstraň duplicity mezi instancemi, ale zachovej navazující rozhodnutí, pokud mění právní závěr.
4. Rozhodnutí označ jako přímo relevantní, analogické nebo pouze kontextové.
5. Zvlášť doplň SDEU, pokud český soud aplikoval databázovou směrnici, autorské směrnice nebo GDPR.
6. Výstup dokonči i tehdy, když přímé české rozhodnutí nenajdeš. Uveď hledané varianty a co nelze garantovat.

## Výstup

U každého rozhodnutí uveď datum, soud, spisovou značku, skutkový vztah ke scrapingu, rozhodnou právní větu vlastní parafrází, procesní výsledek a funkční CODEXIS odkaz.

Nepoužívej slovo „veškerá“ bez kvalifikace. Bez kompletní indexace všech českých rozhodnutí formuluj „nalezená rozhodnutí po vyhledání těchto variant“.
